# MediTap

MediTap is an RFID-based patient medical record management and archiving system powered by ESP32, Next.js, and Firebase. It enables secure patient identification, medical record retrieval, staff management, role-based access control, and RFID-verified record updates through a web-based platform.

## Web stack

- Next.js and TypeScript
- Tailwind CSS
- shadcn/ui component conventions
- Node.js
- Vercel-ready deployment

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.
